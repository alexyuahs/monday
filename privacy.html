Monday – Privacy Policy

Effective date: 2026-11-03 · Last updated: 2026-11-03

Who we are

Monday is a personal, single-user tool developed and used by one individual (GitHub user alexyuahs), referred to here as "the developer" and "the owner". It is not a commercial product and is not offered to other users. The homepage is this site.

What Google user data the app accesses

Monday uses Google OAuth with the single scope https://www.googleapis.com/auth/drive.file. With this scope the app can view and manage only the files and folders that the app itself created in the signed-in user's Google Drive: a folder named Monday-Sync and the Google Docs inside it. The app cannot see, read or change any other file in Google Drive. It does not request access to Gmail, contacts, calendar, location or any other Google service.

The only content the app handles is the owner's own study notes, which the owner chooses to export. The app does not collect or access any other personal information.

How the data is used

The data is used for one purpose only: to create and update documents in the owner's Google Drive so that the owner can use them as sources in NotebookLM. The app does not use Google user data for advertising, profiling, analytics, training of machine-learning models or any other purpose.

Storage and security

  • The app runs on the owner's own computer. The developer operates no server, database or website that receives user data.
  • The OAuth refresh token is stored locally on the owner's computer, in a configuration file that only the owner's operating-system account can read.
  • Documents created by the app are stored in the owner's own Google Drive and protected by the owner's Google account.

Sharing and disclosure

Monday does not transfer, sell or share Google user data with the developer, with third parties or with any other service. Data moves only between the owner's computer and Google's servers over encrypted connections. The owner may separately choose to add the created documents to NotebookLM, which is governed by Google's own terms and privacy policy.

Compliance with Google API Services User Data Policy

Monday's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The app keeps no copy of Google user data outside the owner's computer and Google Drive. Access can be withdrawn at any time at myaccount.google.com/permissions; the stored token can be removed by deleting the configuration entry on the owner's computer, and the created folder and documents can be deleted from Google Drive.

Cookies, analytics and children

This website uses no cookies, analytics or third-party scripts. The app is not directed to children.

Changes to this policy

Any change will be published on this page together with an updated date.

Contact

Questions can be raised as an issue in the GitHub repository of this site (alexyuahs/monday).

Česky (shrnutí)

Nepracuje s žádnými jinými soubory. Vývojář nemá žádný server, data se neposílají nikomu kromě Googlu a nepoužívají se k reklamě, analytice ani trénování modelů. Přihlašovací token je uložený jen v počítači majitele. Přístup lze kdykoli odvolat na myaccount.google.com/permissions. Platí požadavky Google API Services User Data Policy včetně Limited Use.
